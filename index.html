Strict 4-Tier Autonomy & Permission Hierarchy

ShieldDesk enforces strict mathematical boundaries between read-only observability and endpoint modification.

Autonomy Tier Classification Execution Policy Required Sign-Off Eligible Approvers Example Actions
Tier 0 Observation Only Autonomous read & telemetry visualization 0 (Fully Autonomous) System Daemon Attack surface mapping, CVSS calculation, blast radius simulation
Tier 1 Low-Risk / Reversible Pre-flight snapshot + rate-throttled dispatch 1 Approver (Self-approval allowed) system_admin, super_admin, responder Revoke user sessions, block outbound domain, blacklist IP on gateway
Tier 2 Containment / Isolation Human Sign-Off Required + RFC 6238 TOTP MFA 1 Approver (Fast Containment) system_admin, super_admin, responder Quarantine endpoint NIC, isolate database host, deploy OS patch
Tier 3 Break-Glass / Destructive Dual Named SuperAdmin + Strict SoD + Mandatory MFA 2 Distinct Admins (No self-approval) Dual super_admin or system_admin Fleet-wide credential rotation, kernel patch reboot, firewall wipe

Database-Enforced Separation of Duties Invariant

Constraint check_separation_of_duties ensures that for Tier 3 destructive actions, requester cannot approve their own request, and two distinct administrators must independently sign off with hardware tokens. Analysts maintain strict zero write or sign-off authority.

Incident Response Lifecycle

The 3-Horizon Remediation Framework

ShieldDesk structures containment into three clear operational horizons to prevent both immediate data exfiltration and long-term recurrence.

Horizon 1 • Minutes

Immediate Containment

Immediate cryptographic severance of adversary access vectors. Eliminates command-and-control communication while preserving volatile forensic memory.

  • Quarantine host network interfaces & flush ARP tables
  • Invalidate all active OAuth session tokens and cookies
  • Trigger pre-flight LVM snapshot before executing isolation
Horizon 2 • Hours

Short-Term Patching

Rapid remediation of root-cause vulnerabilities identified by Trivy CVE scans and ML exploitation probability predictions.

  • Apply verified vendor security packages across fleet
  • Quarantine suspicious payload binaries and DLL drops
  • Rotate compromised service account tokens and secrets
Horizon 3 • Days / Weeks

Long-Term Zero Trust

Permanent architectural hardening to structurally eliminate the entire attack class and satisfy continuous regulatory compliance matrices.

  • Deploy microsegmentation firewall rules across cloud VPCs
  • Implement strict mTLS X.509 certificate authentication
  • Anchor incident remediation proof to Merkle audit vault
